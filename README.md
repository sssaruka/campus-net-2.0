# campus-net-2.0

校内网 2.0 · 网页版（纯静态，无需后端）

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 前台首页：一行快捷入口 + 企微路径 / 真题资源 / 校园社区 三栏并排 |
| `style.css` | 前台样式（清新校园蓝主题） |
| `app.js` | 前台渲染脚本（读取数据、搜索过滤） |
| `admin.html` | 管理后台页面 |
| `admin.css` | 后台样式 |
| `admin.js` | 后台逻辑：各模块增删改查、审核、封禁 |
| `data.js` | 共享数据层，数据存 localStorage，前台与后台共用 |

## 后台功能

打开 `admin.html`，左侧为功能模块列表：

- **后台概览**：数据统计 + 待处理事项 + 功能卡片入口
- **快捷入口**：增删改首页一行的高频入口（图标 / 名称 / 路径 / 顺序 / 启用）
- **企微路径**：新增、编辑办事路径与直达链接，可上架 / 下架
- **真题资源**：审核用户上传 → 归类科目 → 开关前台展示
- **校园社区**：按板块审核帖子，支持封禁 / 恢复 / 删除
- **用户中心**：查看用户资料与活跃度，禁言 / 封禁 / 角色调整
- **公告与设置**：首页滚动公告、真题分类字典、恢复默认数据

后台改动写入 localStorage，刷新前台即可看到最新效果。

## 本地预览

直接双击 `index.html` 打开即可；后台入口在导航栏右侧「后台管理」。

数据存在浏览器本地，换浏览器或清除缓存会回到初始演示数据。
